# Restricciones del Proyecto — Cancha Gremio

## Stack Obligatorio
- Backend: Python 3.12+, FastAPI, SQLAlchemy 2.0
- Frontend: React 18+, TypeScript 5+, Vite 6+, TailwindCSS 4+
- BD: PostgreSQL 17+ en Docker
- Paquetes Node: pnpm (prohibido npm/yarn)
- Paquetes Python: venv (prohibido conda/poetry)

## Seguridad
- Variables sensibles en .env (nunca en el código)
- Nunca subir node_modules ni .env al repositorio

# Changelog

Registro de cambios importantes del proyecto Cancha Gremio.

## [0.1.0] - 2026-09-21

### Added
- Estructura inicial del proyecto con Gitflow configurado
- Backend FastAPI con autenticación JWT y roles
- Frontend React con TypeScript y Vite
- Base de datos PostgreSQL con migraciones Alembic
- Docker Compose para entorno de desarrollo
- CRUD de reservas con control de disponibilidad
- CRUD de eventos para administrador
- Gestión de clientes y campos deportivos
- Sistema de tarifas y precios por horario
- Dashboard administrativo con reportes
- Landing page pública
- Sistema de recuperación de contraseña
- Control de puntualidad y bloqueo por impuntualidad
- Plantilla de Pull Request
- Manual de estándares de codificación
- Licencia MIT

### Fixed
- Corrección de Network Error en Dashboard
- Solución de error 422 al registrar usuario
- Corrección de mapeo de correo electrónico en modal de inscripción
- Solución de errores de redirección y proxy de enrutamiento

### Changed
- Rediseño de Landing Page con estilo premium oscuro
- Migración de estructura de carpetas a estándar del proyecto
